= Установка на Linux
:experimental:

Программа «QS: Спецодежда» распространяется в виде пакетов для различных дистрибутивов Linux.
Ниже описан порядок установки через пакетный менеджер с подключением нашего репозитория.

После установки программы вам также потребуется сервер баз данных MariaDB или MySQL.
Инструкция по его установке находится в разделе xref:install.adoc#InstallDBServer[Установка сервера базы данных].

[#alt-linux]
== AltLinux

Инструкция проверена на AltLinux p11 (11.x).

=== Подключение репозитория

Добавьте наш репозиторий в список источников пакетов:

[source,bash]
----
echo "rpm https://repo.qsolution.ru/alt/workwear x86_64 workwear" \
    | sudo tee /etc/apt/sources.list.d/qsolution-workwear.list
----

Обновите список пакетов:

[source,bash]
----
sudo apt-get update
----

=== Установка

[source,bash]
----
sudo apt-get install qs-workwear
----

После установки программа появится в меню приложений в разделе *Офис* под названием *QS: Спецодежда*.

Запустить программу также можно из терминала:

[source,bash]
----
qs-workwear
----

=== Обновление

Обновление до новой версии выполняется стандартными средствами:

[source,bash]
----
sudo apt-get update
sudo apt-get install qs-workwear
----

[#astra-linux]
== Astra Linux Special Edition

Пакет предназначен для Astra Linux Special Edition 1.8 x86_64. Установка и запуск проверены на сборке 1.8.6.39.
Для установки зависимостей подключите расширенный репозиторий Astra Linux, который соответствует версии вашей системы.
Порядок подключения приведён в https://docs.astralinux.ru/latest/guide/compound/repo/add_install/[документации Astra Linux].

=== Подключение репозитория

Загрузите открытый ключ репозитория и добавьте источник пакетов.

[source,bash]
----
sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSL https://repo.qsolution.ru/astra/workwear/keyring.gpg \
    -o /etc/apt/keyrings/qsolution-astra.gpg
sudo chmod 0644 /etc/apt/keyrings/qsolution-astra.gpg
echo 'deb [arch=amd64 signed-by=/etc/apt/keyrings/qsolution-astra.gpg] https://repo.qsolution.ru/astra/workwear/ ./' \
    | sudo tee /etc/apt/sources.list.d/qsolution-workwear.list
----

=== Установка и обновление

Выполните эти команды для установки или обновления пакета.

[source,bash]
----
sudo apt-get update
sudo apt-get install qs-workwear
----

Откройте «QS: Спецодежда» из меню *Офис* или выполните в терминале команду `qs-workwear`.
