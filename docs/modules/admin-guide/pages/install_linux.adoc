= Установка на Linux
:experimental:

Программа «QS: Спецодежда» распространяется в виде пакетов для различных дистрибутивов Linux.
Ниже описан порядок установки через пакетный менеджер с подключением нашего репозитория.

После установки программы вам также потребуется сервер баз данных MariaDB или MySQL.
Инструкция по его установке находится в разделе xref:install.adoc#InstallDBServer[Установка сервера базы данных].

[#alt-linux]
== AltLinux

Инструкция проверена на AltLinux p11 (11.x).

=== Подключение репозитория

Добавьте наш репозиторий в список источников пакетов:

[source,bash]
----
echo "rpm https://repo.qsolution.ru/alt/workwear x86_64 workwear" \
    | sudo tee /etc/apt/sources.list.d/qsolution-workwear.list
----

Обновите список пакетов:

[source,bash]
----
sudo apt-get update
----

=== Установка

[source,bash]
----
sudo apt-get install qs-workwear
----

После установки программа появится в меню приложений в разделе *Офис* под названием *QS: Спецодежда*.

Запустить программу также можно из терминала:

[source,bash]
----
qs-workwear
----

=== Обновление

Обновление до новой версии выполняется стандартными средствами:

[source,bash]
----
sudo apt-get update
sudo apt-get install qs-workwear
----

[#astra-linux]
== Astra Linux Special Edition

Пакет предназначен для Astra Linux Special Edition 1.8 x86_64.

=== Подключение репозиториев Astra Linux

Для установки зависимостей подключите основной и расширенный репозитории Astra Linux для установленной версии ОС. Расширенный репозиторий содержит пакеты Mono и GTK#, которых может не быть на установочном DVD.

Если в APT подключён только установочный диск (`cdrom:`), откройте список источников:

[source,bash]
----
sudoedit /etc/apt/sources.list
----

Обычно достаточно убрать символ `#` в начале строк основного и расширенного репозиториев и поставить `#` перед строкой `deb cdrom:` с установочным диском.

Для Astra Linux 1.8.6 строки сетевых репозиториев должны выглядеть так. Если их в файле нет, добавьте их:

[source,text]
----
deb https://download.astralinux.ru/astra/frozen/1.8_x86-64/1.8.6/main-repository/ 1.8_x86-64 main contrib non-free non-free-firmware
deb https://download.astralinux.ru/astra/frozen/1.8_x86-64/1.8.6/extended-repository/ 1.8_x86-64 main contrib non-free non-free-firmware
----

Если у вас другая версия ОС, выберите адреса репозиториев для неё по https://docs.astralinux.ru/latest/guide/compound/repo/add_install/[инструкции Astra Linux].

Сохраните файл.

=== Подключение репозитория Quality Solution

Загрузите открытый ключ репозитория и добавьте источник пакетов.

[source,bash]
----
sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSL https://repo.qsolution.ru/astra/workwear/keyring.gpg \
    -o /etc/apt/keyrings/qsolution-astra.gpg
sudo chmod 0644 /etc/apt/keyrings/qsolution-astra.gpg
echo 'deb [arch=amd64 signed-by=/etc/apt/keyrings/qsolution-astra.gpg] https://repo.qsolution.ru/astra/workwear/ ./' \
    | sudo tee /etc/apt/sources.list.d/qsolution-workwear.list
----

=== Установка и обновление

После подключения репозиториев обновите списки пакетов и установите программу. Для обновления программы используйте те же команды.

[source,bash]
----
sudo apt-get update
sudo apt-get install qs-workwear
----

Откройте «QS: Спецодежда» из меню *Офис* или выполните в терминале команду `qs-workwear`.
